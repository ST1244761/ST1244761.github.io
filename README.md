# My Wrangler Studios Portfolio

Personal portfolio for the GitHub account [ST1244761](https://github.com/ST1244761), published at [https://st1244761.github.io/](https://st1244761.github.io/). The layout follows the simple, project-category structure of the supplied portfolio example while describing only projects that exist.

## Pages and content

- `index.md` is the home page and project list.
- `about.md` contains the about page.
- `notebook.md` contains a short project-learning journal.
- `_config.yml` supplies the site title, description, URL, and GitHub Pages theme.

The site uses GitHub Pages' supported `jekyll-theme-minimal` theme, which supplies the page layout and responsive styling. No JavaScript, packages, or build tools are needed for these Markdown content updates.

## Updating the site

Edit the Markdown pages, preview your changes, then commit and push them to `main`. GitHub Pages builds and publishes the updated site automatically.
